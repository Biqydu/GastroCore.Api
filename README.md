# GastroCore.API 👨‍🍳

Modern, high-performance Backend API designed for **Multi-Brand Ghost Kitchens**.

## 🚀 Architectural Blueprint

This project is a playground for high-end enterprise architecture patterns, shifting away from traditional layered structures to maximize maintainability and raw CPU performance.

- **Vertical Slice Architecture:** Features are organized around distinct business capabilities (Slices) rather than technical layers, utilizing **MediatR** for CQRS pattern implementation.
- **Result Pattern (`ErrorOr`):** Functional error handling that eliminates heavy stack traces generated by throwing exceptions for business validation failures, ensuring predictable response times.
- **Transactional Consistency:** Atomic SQL operations to handle data integrity across shared inventory states in multi-brand operations.


## 🛠️ Tech Stack

- **Runtime:** .NET 10
- **Database:** PostgreSQL
- **Architecture Tools:** MediatR, FluentValidation, Entity Framework Core
- **Documentation:** Scalar
